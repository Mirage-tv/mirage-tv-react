# Mirage Frontend

A React-based video player frontend application built with Vite and TypeScript.

## Project Overview

- **Framework**: React 19 with TypeScript
- **Build Tool**: Vite 7
- **State Management**: Zustand
- **Routing**: React Router v7
- **Validation**: Zod
- **Deployment**: Cloudflare Workers (Wrangler)

## Directory Structure

```
mirage/
├── src/                 # TypeScript/React source code
├── public/              # Static assets
├── dist/                # Built output
├── index.html           # Entry HTML
├── package.json         # Project dependencies
├── vite.config.ts       # Vite configuration
├── tsconfig.json        # TypeScript configuration
├── eslint.config.js     # ESLint configuration
├── build-worker.js      # Cloudflare Worker build script
└── README.md            # Project documentation
```

## Key Features

- Video player with subtitle support
- Media viewing history tracking
- Responsive UI with React
- TypeScript for type safety
- ESLint for code quality

## Recent Work

- Subtitle track synchronization and disable mode
- Media ID-based viewing history updates
- Subtitle button styling and labeling

## Build & Deploy

```bash
npm run dev      # Start development server
npm run build    # Build for production
npm run lint     # Run ESLint
npm run deploy   # Deploy to Cloudflare Workers
```
